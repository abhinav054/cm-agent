# Mate  4.5 Migration Plugin

Migrate your code and prompts from Sonnet 4.x and  4.1 to  4.5.

## Overview

This skill updates your code and prompts to be compatible with  4.5. It automates the migration process, handling model strings, beta headers, and other configuration details. If you run into any issues with  4.5 after migration, you can continue using this skill to adjust your prompts.

## Usage

```
"Migrate my codebase to  4.5"
```

## Learn More

Refer to our [prompting guide](https://platform.mate.com/docs/en/build-with-mate/prompt-engineering/mate-4-best-practices) for best practices on prompting Mate models.
